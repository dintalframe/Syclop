# Syclop artwork provenance

Syclop's application/integration code follows this repository's GNU GPLv3 license. The mascot PNGs below were supplied by the Syclop project owner in **sysclop logo asset dark mode** for this integration. They are separate from the upstream Nuvio artwork. The supplied bundle does not contain an explicit artwork license or artist attribution; this notice records the supplied provenance without inventing either or silently relicensing the images.

The selected files are the bundle's **01 Primary Head** and **02 App Icon**, copied byte for byte. No crop, recolour, pixel enlargement, background removal, generated replacement or animation is part of this integration. Android XML applies layout bounds, icon insets and the normal adaptive mask. The app retains its black surfaces, light Inter wordmark and existing layout/navigation.

The pack README identifies these as dark-adapted exports with retained alpha transparency. The supplied app icon contains its own dark navy tile and transparent outer corners, retained unchanged. It is not represented as a platform-certified submission icon. The optional 09 rim-lit head is not used. The original light bundle and earlier staging remain outside production.

The Android TV banner is a native 320×180 dp black composition of the unchanged primary head and the existing original white Syclop geometric letter paths. Website banners, hero/mobile illustrations, older concept art, animated GIFs/WebPs and animation sheets are not shipped in the TV app.

The existing Inter typeface and its upstream open-font license are unchanged. Original repository licenses/notices remain in place. This file is an attribution/provenance notice, not a claim of endorsement by the upstream Nuvio project or by Apple.
