# Owned Android TV playback fixture

This isolated qualification branch contains synthetic six-second H.264/AAC video and static add-on metadata for normal HTTPS playback testing. It contains no application build, credentials, user data or external footage/audio. The video and tone were generated entirely from FFmpeg built-in testsrc2 and sine sources. The exact generation command, tool hash and output identity are in owned-api36/GENERATION.json. The one-pixel poster is a generic fixture.

This branch does not change the application or mark an APK stable.
