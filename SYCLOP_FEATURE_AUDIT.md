# Syclop feature and verification audit

Audit date: 2026-10-25. Syclop is an independent project derived from [NuvioTV](https://github.com/NuvioMedia/NuvioTV) `b36db80`, with its GNU GPLv3 [license](LICENSE) and upstream attribution retained, plus the applied Syclop source changes in the maintainer workspace. Publication and installed-artifact state are tracked separately. This is a source audit, not a claim that every feature has passed account or TV testing. Private account details and device captures are not published in this audit.

**Connected-service-only policy in source:** Local P2P is disabled by immutable player/backend guards, and packaging excludes the local torrent-engine library. Playback requires a private, expiring, exact-URL HTTPS grant from Syclop's authenticated native debrid resolver or connected cloud library, bound to the initiating viewer/account; cached links cannot acquire a new viewer's authority. Guards also cover Exo/MPV, external-player and browser entry points. Downloaded executable JavaScript/Cloudstream DEX plugins are disabled, including stored/cached providers and direct test/load routes. Declarative Express/Magnify and Stremio JSON discovery remain, but their supplied URLs alone cannot authorize playback. The earlier 690-test optimized baseline was inspected to confirm the local torrent-engine library is absent. The accepted behavioral baseline passed 1,274 selected tests in 175 suites, and packaging confirmed the local torrent-engine library is absent. The current initialization release passed 1,325 selected tests in 186 suites, optimized Android packaging and the sampled device checks below. One native AllDebrid MKV played smoothly through Exo with viewer-confirmed picture/sound; a larger M2TS/MPV sample stuttered, so broader playback acceptance remains open. This is not a packet-capture claim. Executable-plugin and arbitrary direct-URL compatibility are intentionally restricted because unverifiable code or URLs could bypass the requested service-only path.

Syclop includes a bounded Express adapter, native RD/AD device login, MAL catalogs/Library controls, Trakt manual actions, Simkl V2 device authorization and portable local backups. Arbitrary provider compatibility, cross-catalog anime identity, remaining account verification, restricted profiles and casting still have material gaps. No decompiled third-party application implementation or proprietary provider definitions were copied into Syclop.

## Transport evidence and acceptance boundary

The recorded sanitized playback evidence contained an **HTTPS** AllDebrid download URL. Earlier “HTTP” shorthand described the HTTP family and is not evidence of an insecure URL or of a transport-policy failure. The [official AllDebrid API](https://docs.alldebrid.com/#download-link) requires HTTPS API calls but includes both HTTP download examples and an HTTPS streaming example; its unlock/streaming/delayed parameter lists expose no documented HTTPS-selection flag. This does not establish the default frequency or current behavior for every file. The applied grant policy accepts HTTPS only; authenticated HTTP-only results are rejected rather than rewritten. No undocumented parameter or URL scheme rewrite has been added. Processing statuses observed earlier (`0`, then `1`) do not establish permanent cache absence. The earlier `042d0bda…` APK advanced to a Real-Debrid attempt after processing, and a separate native AllDebrid READY MKV decoded smoothly through Exo with viewer-confirmed picture/sound. Installed fallback rejects non-policy URLs before cache/routing success, without rewriting HTTP to HTTPS. The first M2TS Exo failure/MPV stutter remains unresolved. The earlier diagnostic INFO sample establishes software VC-1 decoding and output drops with cached data, not a fix or a network benchmark; a successful separate sample does not establish general transport/format compatibility or an automatic engine-switch path. The inspected [FFmpeg revision](https://raw.githubusercontent.com/FFmpeg/FFmpeg/a7522f3fef/libavcodec/mediacodecdec.c) has no VC-1/WMV3 MediaCodec wrapper; [MPV codec allowlisting](https://mpv.io/manual/master/#options-hwdec-codecs) only permits available hardware paths.

## Android TV compatibility boundary

The declared minimum is Android 7.0 / API 24, with packaged native libraries for arm64-v8a, armeabi-v7a, x86 and x86_64. These build targets do not establish stable operation on every TV. Real-device acceptance in this record is scoped to the NVIDIA Shield Pro; lower-memory devices, other vendors, older API fallbacks and hardware-specific codec/HDR/audio paths still need representative runtime testing.

An inspected local universal release contained 4 KiB ELF load-segment alignment in the 64-bit `libconscrypt_jni.so` and `libiamf.so` libraries. APK ZIP alignment passed the 16 KiB check, but that does not repair native ELF alignment. Updating or rebuilding those dependencies and testing a 16 KiB-page environment remain open compatibility work, as described in [Android's page-size guidance](https://developer.android.com/guide/practices/page-sizes). This is separate from the accepted Shield results; no 16 KiB-device acceptance is claimed.
