# Syclop GitHub presentation

Refresh the existing GitHub Pages site and repository README so visitors can quickly understand Syclop, download the current release, and set up their TV.

## Approach

Keep the existing buildless HTML/CSS site and Syclop mascot. Use a spacious dark layout with blue accents, clear typography, and one prominent download action. A documentation-heavy landing page would preserve the clutter the user wants removed; a new framework or hosting service adds no useful behavior here.

## Page

- Compact header: Syclop, Releases, GitHub.
- Hero: “Your media. Made for TV.” with a short description, Download latest release, and release notes.
- Three brief benefits: remote navigation, connected services, local profiles and watch progress.
- Three setup steps: install, connect an authorized source, start watching.
- Small footer: support, build guide, GPLv3, upstream credit.

Use the latest-release link so the page does not advertise an unpublished version. Keep Android 7.0+ and the requirement to bring media sources visible near setup. Preserve keyboard focus, readable contrast, mobile layout, reduced-motion support, existing CSP, and local assets. Add no trackers, external fonts, dependencies, or autoplay.

## README

Use the same concise introduction and download/setup links. Move detailed build, qualification, native provenance, and registration information behind existing documentation links. Retain license and NuvioTV attribution. Correct setup paths against the released app.

## Verification

Review desktop and mobile browser previews, keyboard navigation, local links, and live GitHub Pages deployment. Preserve the public release's stated verification limits in its release notes.
