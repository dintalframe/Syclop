Checking the MyAnimeList authorization response…

Use a phone on the same home network as your TV. Syclop on the TV checks the connection state and exchanges the code directly with MyAnimeList.

This page has no analytics and sends no requests. The HTTPS host receives the temporary authorization URL; access tokens and the PKCE verifier stay on your TV. A connection expires after five minutes.
