### Browsing on TV

- Grid View opens with compact landscape tiles and a title preview that stays in place as you browse. Continue Watching has its own shortcut.
- Movies, TV, Anime, and Kids use the compact grid when Grid View is selected. Back returns to the poster you opened.
- Syclop's eye mark and blue focus outline carry through the default theme. Screen fades are shorter, and the player timeline updates independently of the other controls.

### Sources and playback

- Real-Debrid and AllDebrid show when an exact file is ready in your connected library. Results without a verified match show unverified availability.
- Express checks the provider's cooldown again before sending a queued request.

### Updating

- One tap downloads and verifies the update, then opens Android's install confirmation when the update offer is active. If Android asks for install permission first, granting it resumes the request.
