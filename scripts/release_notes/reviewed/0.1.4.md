### Browsing and remote controls

- Reach Continue Watching with one Down press from Home when the row is available in Classic, Grid, or Modern.
- Keep the title and controls in place when artwork loads or fails. Return to the same Search, Discover, or Library item when it is still available.
- Show a visible focus outline in both sidebars, including with animations disabled.

### Anime and playback

- Search across the anime catalog using verified episode data from Ani.zip, Kitsu, and MyAnimeList. Use the catalog episode number when a TV season mapping is unavailable and check the selected file against the episode and edition.
- Keep the selected anime episode when reopening Sources from the player. Explain whether episode data is unavailable, the search was incomplete, or no compatible source was found.
- Finish a held remote seek once when the key is released, even if focus moves while the key is held.

### Profiles and setup

- Use a PIN with local profiles. Back restores focus to the viewer card after canceling PIN entry. PIN-protected viewers keep their watch progress inside Syclop.
- Keep first-watch actions visible at larger text sizes and put focus on Cancel when confirming a backup restore or Undo.
